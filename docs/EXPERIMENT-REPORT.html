3 · นี่คือสัญญาณ หรือ noise?

พิสูจน์ด้วย bootstrap (1000×, 90% CI ของ ΔROC)

±0.008 เล็กมาก (452 positives, SE≈0.02) — ต้องเช็ก. LightGBM deterministic (seed variance = 0.000) → ความไม่แน่นอนมาจาก test sampling. resample test 1000 ครั้ง:

ΔROC = 0
B−A (soil อย่างเดียว): [−0.018, +0.003] · คร่อม 0 = noise
D−C (soil ทับ forecast): [+0.002, +0.014] · ไม่คร่อม 0 = ผลจริงเล็กๆ
✅ B−A คร่อม 0 → soil อย่างเดียว = noise  |  D−C ไม่คร่อม 0 → soil ทับ forecast = ผลจริงเล็กๆ (single split — ยังต้องยืนยันด้วย rolling-origin CV ข้ามปี)

6 · งานวิจัยรับรองดีไซน์เดิม

สิ่งที่โปรเจคทำถูกอยู่แล้ว

🚫 ไม่ใช้ SMOTE → calibrate แทน

Carriero 2024: การแก้ imbalance ทำลาย calibration → ตรงกับ unbalanced + isotonic + F2 threshold ของเรา

📅 temporal split (ไม่ random CV)

Ahmadzadeh 2021: temporal coherence ทำให้ random CV ให้คะแนนปลอม → ตรงกับกฎ #1 ของเรา

ความเข้มงวด (PR-AUC/F2 + temporal split + ไม่ใช้ SMOTE) นำหน้างานวิจัย heatwave-ML ที่รายงาน accuracy 96–99.9% (ตัวเลขลวงจาก imbalance)
